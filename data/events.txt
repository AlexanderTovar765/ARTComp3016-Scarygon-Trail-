# The Scarygon Trail - event data
#
# FORMAT
#   [EVENT]   starts an event.   Keys: day, part, text
#   [CHOICE]  starts a choice for the event above (1 to 4 per event).
#             Keys: label, result, food, health, sanity, wagon
#             member = Ma|Pa|Junior|Granny  (optional: health damage/healing hits only that person)
#   Animations (optional, decoration only; a bad name is a warning and never skips the event):
#     scene  = ...   an [EVENT] key: the backdrop and actor shown while the event is on screen.
#                    trail, oxen_stare, map_man, deer, herd, ritual, figure, crowd, tidy_wagon, river,
#                    travellers, oxen_circle, voice, new_road, cook_camp
#     action = ...   a [CHOICE] key: what the family does on the result screen.
#                    feed, eat, rush, ask, buy, refuse, flee, fight, hide, pray, steal, sleep, give,
#                    cross, inspect, shoot, join, wait, build, burn
#   Event key  requires = LowFood|LowWagon|LowHealth  makes the event a DESPERATE VARIANT that
#             replaces the normal event for its slot while that condition is true.
#   part is one of: Dawn, Mid-Morning, Noon, Evening, Night
#   Effects are whole numbers: positive helps the party, negative hurts it.
#   Leave an effect out and it is 0. Stats run from 0 to 100.
#   Lines starting with # are comments. Use plain ASCII (straight quotes).
#   Keep text short: about 200 characters for text, 46 for a label.
#   Every event slot (each day x each part) should have exactly one event.
