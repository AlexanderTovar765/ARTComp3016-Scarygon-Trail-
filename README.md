# The Scarygon Trail

A comedic survival-horror resource-management game inspired by *The Oregon Trail*, built in C++ with SDL3 for COMP3016 (Immersive Game Technologies) Coursework 1.

Every stop on the trail presents a short narrative event, delivered in the same flat, matter-of-fact tone whether it's a broken wheel or something considerably stranger. Manage food, health, sanity and wagon condition, and live with the consequences of your choices.

## Status
Three playable days. Each day has 5 parts (Dawn, Mid-Morning, Noon, Evening, Night), one event per part, four choices per event. Every choice changes the party's Food, Health, Sanity and Wagon, shown as bars in the top panel, and the trail takes a toll after every part. Events are loaded from `data/events.txt`.

- **Sanity changes how trustworthy the game is** (State pattern, `src/NarrativeState.*`): Stable above 60, Unreliable from 30 to 59 (some words and HUD numbers are wrong), Breakdown below 30 (numbers hidden, lies freely). Only the presentation lies; what choices do, and the "what happened" summary, are always true.
- The top panel shows the wagon and oxen under a sky that follows the time of day, plus a 15-dot trail progress strip. It is drawn in code, so there are no image assets.
- The game ends if Health, Sanity or the Wagon reaches 0.

## Scope
The proposal described a longer trail with individual party members. Because CW1 is 30% of the module, the game was scaled to 3 days x 5 parts with shared party stats. The sanity-driven unreliable narration from the proposal is implemented as described.

## Build
Requires Visual Studio 2022 with the "Desktop development with C++" workload. SDL3 (3.4.18, x64) is bundled in `vendored/SDL3`, so no separate install is needed.

1. Open `ScarygonTrail.sln`.
2. Select `Debug | x64` (or `Release | x64`).
3. Press F5 to build and run. `SDL3.dll` is copied next to the executable automatically; output goes to `build/`.

## Controls
- Mouse click or `1`-`4`: pick a choice
- `Esc`: quit

## Project structure
```
src/      C++ source
tools/    balance_sim.cpp, a simulator that plays thousands of games to check difficulty
vendored/ bundled SDL3 headers and x64 libraries
assets/   sprites, fonts
data/     events.txt, loaded at runtime (format explained at the top of the file)
docs/     proposal and AI Development Log
```
